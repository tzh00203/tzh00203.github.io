Research Summary

LLM-Assisted Security Analysis from Source Code to Decompiled Firmware

My research explores how to make LLM-assisted vulnerability discovery more reliable by grounding model reasoning in program-analysis evidence.

Motivation

LLMs can help interpret code and reason about vulnerabilities, but their conclusions are difficult to trust without static evidence. I study how to combine LLM reasoning with taint analysis, source/sink modeling, and path constraints.

Current Work

  • Inferring source and sink specifications for IoT and firmware analysis.
  • Validating taint-flow paths with LLM-generated explanations and constraints.
  • Comparing source-level analysis with Ghidra-generated pseudocode analysis.
  • Building auditable workflows for LLM-based cyber agents.
